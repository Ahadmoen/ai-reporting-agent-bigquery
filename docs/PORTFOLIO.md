# Portfolio summary

**Title:** AI reporting agent on a reconciled BigQuery data layer

**One line:** A Gemini agent that answers sales, digital and reporting questions for a national ISP without ever calculating a number itself, because every figure is resolved and reconciled in BigQuery first.

**Three results to lead with:**
- 168 of 168 periods reconcile between the audited national total and 44 markets.
- Daily and weekly reporting cut generated in 6 to 20 seconds, replacing a manual export and script process, with a completeness check that stopped a false 34% drop from being published.
- GA4 figures moved to the Data API and now match the Analytics screen exactly.

**Skills shown:** BigQuery data modeling for LLM consumption, external tables over spreadsheets, period contracts, reconciliation testing, Cloud Run APIs, Vertex AI Agent Engine with ADK, Gemini Enterprise, GA4 Data API, n8n integration, root cause analysis, documentation and handover.
